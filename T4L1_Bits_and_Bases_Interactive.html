Past paper check: negative numbers
2016, Q6(c)

Using an example, describe two's complementation in an 8 bit register. [2]

One mark for the method: flip the bits and add one (or, from the right, copy up to and including the first 1, then flip every other bit). One mark for a correct example, such as 00011011 becoming 11100101.
2022, Q4(c)

Show how −3910 would be represented using sign/magnitude and how it would be represented using two's complement representation in an 8 bit register. [2]

Sign/magnitude: 10100111. Two's complement: 11011001. Try both on the board: set −39 in each number type.
2023, Q14 (part)

Calculate the denary range (highest and lowest) of numbers that can be stored as an integer in an 8 bit register using two's complementation.

Lowest 10000000 = −128. Highest 01111111 = +127. Switch the board to two's complement and look at the range box.

Past paper check: how the examiners word it
2016, Q6(a)

State the meaning of the following terms: (i) Byte. [1] (ii) Word. [1]

(i) A byte is a collection of 8 bits (e.g. 00101010). (ii) A word is the total number of bits that can be manipulated as a single unit by the CPU.
2022, Q4(a)

State the meaning of the term "word". [1]

The total number of bits that can be manipulated as a single unit by the CPU. Notice that "a group of bits" on its own is not enough: the mark is for linking it to the CPU handling it as one unit.
2024, Q4(a)

Describe the term "word length" in relation to a CPU. [1]

The number of bits the CPU can process (manipulate) as a single unit, for example 32 or 64 bits.

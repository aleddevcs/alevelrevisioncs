# Uploads

Put new lesson files here (slides, worksheets, mark schemes, interactive `.html` activities and so on).

1. On GitHub, open this `uploads` folder, then choose **Add file → Upload files**.
2. Drag in the files for one lesson and commit them.
3. Ask Claude to add them, saying which unit, topic and lesson they belong to, for example:
   *“Add the files in uploads as Unit 1, Topic 4, Lesson 4.”*

Claude will move them into `resources/unit<U>/topic<T>/lesson<L>/`, add them to the lesson page and check that
every link works. Files in this folder are not shown on the website until they have been added.

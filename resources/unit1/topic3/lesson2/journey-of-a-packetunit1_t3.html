Part 1: four users, one cable

Four users each need to send a message to someone at the other end, but there is only one cable. A multiplexer (MUX) combines their signals and a demultiplexer (DEMUX) separates them again.

  1. In your own words, what is multiplexing?
    Check

    Several independent data sources are combined so they can be sent along a single route to their destination. A demultiplexer separates them at the other end.

  2. Why is multiplexing needed?
    Check

    Many users can share one line instead of each needing their own cable. That is cheaper to install and maintain, and makes full use of the line's bandwidth.

Part 2: circuit switching vs packet switching

A wants to send to B across a network of switches. Try each method, then break the link between S1 and S2.

Choose a method and press the orange button.
  1. What happened to the circuit-switched call when the link broke? Why?
    Check

    The call dropped. Circuit switching uses one dedicated path, so if any part of it fails the connection breaks and has to be set up again.

  2. Why couldn't C use the S1–S2 link during A's call, even when A wasn't sending anything?
    Check

    The whole path is reserved for A's call for as long as it lasts, so other users can't share those links.

  3. Give one advantage of packet switching that you saw.
    Check

    If a link fails, packets can be sent along a different route. Links are also shared between users, so they are used more efficiently.
